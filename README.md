# DevSpeak — английский для ИСиП

Учебный сайт по английскому языку для студентов специальности «Информационные системы и программирование».
Тема: **Unit 18 · Web Design** (учебник, с. 196–201 и глоссарий).

## Как открыть

Дважды щёлкните по `index.html`. Сайт работает прямо с диска или флешки: без интернета, без VPN и без установки программ.

Рекомендуемые браузеры: Яндекс Браузер, Chrome, Edge, Firefox (свежие версии).

## Что есть на сайте

| Раздел | Что внутри |
|---|---|
| **Уроки** | 7 уроков: адаптированный текст юнита, перевод каждого абзаца, озвучка, всплывающие подсказки к терминам, заметки «Как сейчас», мини-тест и вопросы для обсуждения с образцами ответов (упр. 1–4) |
| **Словарь** | 69 слов из упр. 5, 8–11 и глоссария: транскрипция, произношение, определение, пример с переводом; карточки; 21 аббревиатура (упр. 7) |
| **Игры** | Memory, Speed Translate, Bug Hunt (виселица), Front-end / Back-end, Abbreviation Decoder, Synonym Swap (упр. 6) |
| **Аудирование** | Диктант с проверкой по словам, «Услышь слово», 3 текста на понимание (True / False), говорение по темам упр. 12 с таймером и записью голоса |
| **Подкасты** | 5 выпусков-диалогов с разными голосами, транскриптом, переводом и вопросами |
| **Видео** | 4 анимированных видеоурока с озвучкой и субтитрами EN / RU |
| **Тест** | 20 случайных вопросов из банка в 34 задания, оценка 2–5, разбор ошибок, сертификат для печати |

Прогресс, XP и уровни (Intern → Junior → Middle → Senior → Tech Lead → CTO) хранятся в браузере (`localStorage`). Сбросить прогресс можно ссылкой в подвале сайта.

## Почему работает без VPN

- Нет внешних шрифтов, CDN, YouTube и счётчиков: все файлы лежат в папке сайта.
- Озвучка — готовые MP3 в `assets/audio/` (нейросетевые голоса, записаны заранее).
  Если для фразы нет файла, сайт озвучивает её встроенным синтезатором речи браузера.
- Видеоуроки — это анимация на HTML/CSS с этой же озвучкой, поэтому видеохостинг не нужен.

## Как опубликовать в интернете

Сайт статический, подойдёт любой хостинг:

- **GitHub Pages** — загрузите папку в репозиторий и включите Pages в настройках (Settings → Pages).
- **Российский хостинг** (Beget, Timeweb, REG.RU и др.) — загрузите все файлы в папку сайта через FTP-клиент (например, FileZilla). Это ровно то, о чём говорится в юните: «it must be published or uploaded… using an FTP client».

Для работы сайта не нужны фото страниц учебника (`photo_*.jpg`), папки `tools/` и `.claude/`, их можно не загружать.

## Структура

```
index.html, lessons.html, vocabulary.html, games.html,
listening.html, podcasts.html, video.html, test.html
assets/
  css/style.css          — весь дизайн (светлая и тёмная темы, адаптив)
  js/core.js             — шапка, XP, озвучка, подсказки, общие компоненты
  js/pages/*.js          — логика каждой страницы
  js/data/vocab.js       — слова и аббревиатуры
  js/data/lessons.js     — тексты уроков, вопросы
  js/data/media.js       — подкасты и сценарии видео
  js/data/practice.js    — диктант, тексты, синонимы, сортировка, тест
  js/data/audio.js       — список записанных аудиофайлов (генерируется)
  audio/*.mp3            — озвучка
tools/                   — генерация озвучки (для разработчика)
```

## Как изменить тексты и переозвучить их

1. Отредактируйте нужный файл в `assets/js/data/`.
2. Запустите локальный сервер в папке сайта (`python -m http.server`), откройте `http://localhost:8000/tools/collect.html` и нажмите «Скачать speech.json». Положите файл в `tools/`.
3. Выполните:
   ```
   pip install edge-tts
   python tools/build_audio.py
   ```
   Скрипт создаст недостающие MP3 и обновит `assets/js/data/audio.js`. Для генерации нужен интернет, а готовый сайт работает без него.

## Технологии

HTML5, CSS3 (Grid, Flexbox, container queries, custom properties), JavaScript без фреймворков, Web Speech API (запасная озвучка), MediaRecorder (запись голоса), localStorage.
